    2 equivalence(s) de point declaree(s) :

      "Flux totalise crete" : magnetostat <=> vide1500
        motif : le flux totalise a vide NE DEPEND PAS de la vitesse : lamA =
                Ntc*sum(sign(P).*R.PhiT) est magnetostatique. La reference est lue
                dans l'essai a 1500 tr/min parce que c'est la qu'ANSYS l'enregistre,
                non parce que la grandeur y serait liee. Les deux FEM qui precedent,
                elles, portent bien om : elles derivent de lamA*om.

      "Constante de FEM k_E" : vide1500 <=> balayage
        motif : les deux cotes sont a 1500 tr/min. Modele : kE = max(env)/M.speed.
                Reference : interp1(nS,ES,1500)/1500, c'est-a-dire le balayage
                INTERPOLE A 1500 tr/min. Le dossier "balayage" est le vehicule de la
                donnee, pas le point de fonctionnement.

  ---- 3. SOUS UN MEME ESSAI DE REFERENCE ----
    C'est la forme sous laquelle le lecteur rencontre le defaut :
    des barres voisines, sous la meme etiquette de famille, qui ne
    sont pas a la meme condition d'essai.
    Le point de modele est d'abord ramene par les equivalences
    declarees : une difference de NOM qui n'est pas une difference
    de CONDITION ne doit pas compter comme une divergence.
