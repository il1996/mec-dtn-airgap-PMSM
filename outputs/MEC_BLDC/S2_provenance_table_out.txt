  ---- 0. COMMENT LIRE CE TABLEAU ----
    Chaque operande est remonte a ses RACINES par le graphe
    d'affectation complet du programme. Trois natures de racine :
      solveur:<nom>@<ligne>  une resolution du MEC
      FEA:<dossier>          un import .tab, nomme par l'ESSAI ANSYS
                             d'ou il sort -- c'est cet essai qui fixe
                             le point de fonctionnement
      cache:<fichier>        une carte precalculee relue d'un .mat
    et le verdict de nature qui en decoule :
      CALCULE (reseau) / EXPORT ANSYS / MIXTE / ENTREE DECLAREE

    ENTREE DECLAREE ne veut pas dire "depend de M" : toute grandeur
    calculee depend de M par la geometrie et les materiaux. Cela veut
    dire "ne remonte a AUCUN solveur ni AUCUN import", donc n'est
    qu'un parametre recopie. C'est la nature exacte du defaut S1.

    POINT DE FONCTIONNEMENT. Cote reference il est donne par le
    dossier d'essai. Cote modele il est donne par la vitesse
    traversee, avec une regle explicite : toute grandeur descendant
    de drive_mec est au point du MEC, parce que la vitesse y est un
    RESULTAT (nMt) et non une donnee. Les six etiquettes possibles :
      magnetostat  vide-1500  vide-nnl  EF-charge  MEC-charge  balayage

  ---- 4. Q3 : LES DEUX COTES SONT-ILS AU MEME POINT ? ----
    NON BLOQUANT ICI. C'est le materiau du bloc S3, qui decidera.

    equivalences de point DECLAREES (signalees par la regle, mais
    n'en sont pas -- motif verifiable dans le source) :
      #16 Flux totalise crete          magnetostat contre vide-1500
         motif : le flux totalise a vide NE DEPEND PAS de la vitesse (lamA =
                 Ntc*sum(sign(P).*R.PhiT), magnetostatique, ligne 288-289). La
                 reference est lue dans l'essai a 1500 tr/min parce que c'est la que
                 ANSYS l'enregistre, non parce que la grandeur y serait liee. Les FEM
                 des lignes 14-15, elles, portent bien om : elles derivent de lamA*om.
      #26 Constante de FEM k_E         vide-1500 contre balayage
         motif : LES DEUX COTES SONT A 1500 tr/min. Modele : kE = max(env)/M.speed
                 (ligne 646). Reference : interp1(nS,ES,1500)/1500, c'est-a-dire le
                 balayage INTERPOLE A 1500 tr/min. Le dossier "balayage" n'est que le
                 vehicule de la donnee, pas le point de fonctionnement.
